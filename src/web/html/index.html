        X 功能是如何工作的？

        CyberChef 有一个上下文帮助功能。只需将光标悬停在您想了解更多的功能上，然后按键盘上的 F1 即可获取有关它的信息。现在就试试吧，将光标悬停在此文本上并按 F1！


        我可以用 CyberChef 做什么？

        CyberChef 中有 数百个 操作，让您可以轻松执行简单和复杂的任务。以下是一些示例：

        • 解码 Base64 编码的字符串
        • 将日期和时间转换到不同的时区
        • 解析 Teredo IPv6 地址
        • 从十六进制转储转换数据，然后解压缩
        • 解密并反汇编 shellcode
        • 将多个时间戳显示为完整日期
        • 对不同类型的数据执行不同的操作
        • 使用输入的部分作为操作的参数

        我可以直接从文件加载输入吗？

        可以！只需将文件拖到输入框并放下即可。

        CyberChef 可以处理最大约 2GB 的文件（取决于您的浏览器），但某些操作在处理这么多数据时可能需要很长时间。

        如果输出大于某个阈值（默认 1MiB），它将以可下载文件的形式呈现给您。如果需要检查，可以在输出中查看文件的片段。


        如何一次对多个输入运行操作 X？

        也许您有 10 个需要解析的时间戳，或者 16 个具有相同密钥的编码字符串。

        "Fork"（分叉）操作（在"流程控制"类别中找到）将输入逐行拆分，并对每行分别运行所有后续操作。然后每个输出都显示在单独的行上。这些分隔符可以更改，因此如果您的输入以逗号分隔，您可以将拆分分隔符更改为逗号。

        点击这里查看示例。


        "Magic"（魔法）操作是如何工作的？

        "Magic"操作使用多种方法来检测编码数据以及可用于理解它的操作。这些方法的技术描述可以在这里找到。

        是什么
        
                                
        一个简单、直观的 Web 应用程序，用于分析和解码数据，无需处理复杂的工具或编程语言。CyberChef 鼓励技术人员和非技术人员探索数据格式、加密和压缩。

        

                                
        为什么
        
                                
        在现代世界中，数字数据有各种形状、大小和格式 – CyberChef 帮助在一个易于使用的平台上理解这些数据。

        


                                
        如何使用
        
                                
        界面设计以简单为核心。复杂的技术现在就像拖放一样简单。简单的功能可以组合起来构建一个"配方"，可能会产生复杂的分析，可以与其他用户共享并与他们的输入一起使用。
        
                                
        For those comfortable writing code, CyberChef is a quick and efficient way to prototype solutions to a problem which can then be scripted once proven to work.

        


                                
        Who
        
                                
        It is expected that CyberChef will be useful for cybersecurity and antivirus companies. It should also appeal to the academic world and any individuals or companies involved in the analysis of digital data, be that software developers, analysts, mathematicians or casual puzzle solvers.

        


                                
        Aim
        
                                
        It is hoped that by releasing CyberChef through GitHub, contributions can be added which can be rolled out into future versions of the tool.

        


                                
        
                                
        There are hundreds of useful operations in CyberChef for anyone working on anything vaguely Internet-related, whether you just want to convert a timestamp to a different format, decompress gzipped data, create a SHA3 hash, or parse an X.509 certificate to find out who issued it.
        
                                
        It’s the Cyber Swiss Army Knife.

            下载 CyberChef
            
                    
            
                    
            
                        
            
                            CyberChef 完全在您的浏览器中运行，没有服务器端组件，这意味着您的输入数据和配方配置不会发送到任何地方，无论您使用的是 CyberChef 的实时官方版本还是下载的独立版本（假设它未被修改）。
                        
            
                        
            
                            有三个操作会调用外部服务，分别是从 wikimedia.org 下载地图图块的"Show on map"操作、使用 Google 或 Cloudflare 服务解析 DNS 请求的"DNS over HTTPS"操作，以及调用您输入的配置 URL 的"HTTP request"操作。您可以使用浏览器的开发者控制台（F12）并查看网络选项卡来确认发出了哪些网络请求。
                        
            
                        
            
                            如果您想下载自己的 CyberChef 独立副本以在隔离网络中运行或在互联网连接有限或没有的地方运行，您可以在下面获取包含整个 Web 应用程序的 ZIP 文件。这可以在本地运行或托管在 Web 服务器上，无需任何配置。
                        
            
                        
            
                            请注意，独立版本永远不会自动更新，这意味着在您手动重新下载较新版本之前，它不会收到错误修复或新功能。
